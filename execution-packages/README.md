# Spline Phase Execution Packages

This directory contains agent-agnostic execution packages for every delivery phase.

Each package includes:
1. Scope and objective
2. Inputs and prerequisites
3. Detailed work breakdown structure
4. Deliverables
5. Acceptance criteria
6. Evidence requirements
7. Risk controls
8. Hand-off checklist to next phase

## Package index

- `phase-0-foundation-readiness/package.md`
- `phase-1-dependency-legal-lock/package.md`

- `phase-4-svg-primary-pipeline/package.md`

- `phase-6-ux-platform-integration/package.md`
- `phase-7-quality-hardening/package.md`
- `phase-8-app-store-launch/package.md`

## Operating policy

- Phase cannot be closed without evidence artifacts committed.
- `sessions.md` must be updated at the end of each execution session.
- Any scope change requires ADR update or a new ADR.
- Any dependency change requires license and transitive review evidence.
